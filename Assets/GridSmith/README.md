GRID BASE

The sample scene uses 2D sprites by default, this requires the Unity 2D Sprites package

Use the Grid prefabs to place grid controllers in your scene.

Use the 'Load On Start' option to load the grid when you play the scene.

Use 'Use Alt' to alternate between Grid Tile and Grid Tile Alt objects when spawning the grid.

Set the dimensions of your grid (min 1)

The grid will spawn at the position of the GridBase object.

Use the offset to put space between your tiles.
